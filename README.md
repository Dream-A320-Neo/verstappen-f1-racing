## 这是什么

一个从头写起的 F1 竞速游戏：原生 WebGL 渲染、自研车辆物理、六条真实赛道轮廓。
所有代码压在一个自包含的 `verstappen-racing.html` 里 —— 没有构建产物以外的依赖，
可以直接丢到任何静态托管上，也可以离线双击打开。

## 玩法与特性

### 比赛模式

| 模式 | 说明 |
|---|---|
| **大奖赛（RACE）** | 20 台车、3 圈竞速，与 AI 抢位，含轮胎磨损与 ERS |
| **单圈计时（TIME TRIAL）** | 单人刷圈，记录并对比最快圈 |
| **无尽挑战（ENDLESS）** | 圈速与难度随时间递增，撞墙扣分，冲最高分 |

### 车辆物理

- **渐进式转向**：打方向约 0.33 秒到满舵，转向量再走一条指数 1.5 的响应曲线 ——
  角速度「先慢后快」，小输入时车头不会猛地一摆
- **速度自适应收敛**：135 km/h 以下转向最灵活，越往高速越收敛
- **真实抓地模型**：干地 / 半雨 / 全雨三种路面，五种轮胎配方各有抓地系数
- **轮胎磨损**：磨损越高抓地越低，进站可换胎
- **ERS**：可充能、可释放的额外动力
- **尾流（slipstream）**：跟车越紧，直道越快

### 渲染

- **原生 WebGL 1.0**：单文件三角网格世界，无 three.js 之类的依赖
- **赛道分层**：路面 → 立体路肩 → 缓冲区（沥青/砂石分级）→ 草地 → 护栏
- **块状路肩**：红白相间的立体路肩，每块带接缝，弯心处不再是连续长条
- **维修区**：进站口/出站口引导线、限速、挡墙
- **两种镜头**：第三人称追尾（刚性绑定车头，位置与视线都零滞后）· 车手视角
- **动态天气与时间**：黄昏、夜景、雨雾

### 其他

- **全程手柄支持**：RT 油门 / LT 刹车 / 左摇杆转向 / 振动反馈
- **20 支车队涂装**：按真实车队色板绘制
- **中文语音无线电**：超车、丢位、撞墙、最快圈都有语音提示
- **存档**：最高分、最快圈、设置项持久化

## 操作方法

| 按键 | 功能 |
|---|---|
| `W` / `↑` | 油门 |
| `S` / `↓` | 刹车 |
| `A` `D` / `←` `→` | 转向 |
| `空格` | ERS 加速 |
| `C` | 切换视角（第三人称 / 车手） |
| `P` | 暂停 |
| `R` | 重新开始 |
| `M` | 静音 |

**手柄**：RT 油门、LT 刹车、左摇杆转向、A 键 ERS。

## 快速开始

```bash
# 方式一：直接打开
双击 verstappen-racing.html

# 方式二：用本地服务器（推荐，避免某些浏览器的 file:// 限制）
npx serve .
# 然后打开 http://localhost:3000/verstappen-racing.html
```

要求：任何支持 **WebGL 1.0** 的现代浏览器（Chrome / Edge / Firefox / Safari）。

## 项目结构

```
.
├── verstappen-racing.html       ← 构建产物（单文件，直接可玩）

│   ├── 03-cars.js               ← 车辆数据（车队、轮胎配方、抓地模型）
│   ├── 04-race.js               ← 比赛逻辑（物理、AI、碰撞、圈数、天气）

```

## 开发

```bash
# 构建（把 8 个模块拼进 shell.html，输出单文件 HTML）
node build.mjs

# 跑测试（10 个套件，不需要浏览器：用假 DOM + 桩 WebGL）
node tests/all.js
```

测试覆盖：工具函数与赛道生成 · 车辆物理与轮胎 · 比赛流程与碰撞 · HUD 渲染 ·
音频调度 · 游戏集成 · 构建产物 · 加料功能 · 长时间浸泡 · 3D 网格安全性与障碍惩罚。

### 设计要点

- **世界尺度**：以 66.67 世界单位 = 1 米建模，避免远处深度精度问题
- **网格预算**：所有网格必须低于 65535 顶点（WebGL 1.0 的 `Uint16` 索引上限），
  大网格（护栏透明面）按块切分
- **赛道生成**：控制点 → 样条 → 按 3 米分段 → 曲率/路肩/缓冲区宽度逐段推导
- **相机刚性**：第三人称相机的位置和注视方向都直接用车身真实航向，
  不做低通平滑，否则车身在画面里会显得转向滞后
